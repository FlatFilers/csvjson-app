## Request flow

`index.php` → ENVIRONMENT (`development` unless SERVER_NAME contains `csvjson.com`) → CI router (`routes.php`: default controller `csvjson`) → tool controller (inherits `MY_Controller`) → `application/views/page.php` layout + tool view + `assets.php` script tags → browser runs conversion client-side via `js/csvjson/*.js` driven by `js/src/*.js`. Telemetry: browser POSTs to `/csv2json/instrument` → MariaDB. Saved permalinks: S3 (production) or `data/` dir (local).
